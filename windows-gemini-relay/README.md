# שרת Gemini למכשירי Android ישנים (Windows 11)

השרת מאפשר לאפליקציית הצ'אט בטלפון Android 4.1.2 לשלוח שאלות למחשב ברשת הביתית. המחשב מתחבר ל-Gemini דרך HTTPS עדכני. מפתח Gemini נשמר בקובץ מקומי במחשב ואינו נשלח ל-GitHub.

## דרישות
- Windows 11
- Python 3.8 ומעלה (ללא התקנת ספריות נוספות)
- חיבור אינטרנט במחשב
- הטלפון והמחשב מחוברים לאותה רשת Wi-Fi

## הפעלה ראשונה
1. הורד את תיקיית windows-gemini-relay מהמאגר.
2. התקן Python 3 אם אינו מותקן, וסמן Add Python to PATH.
3. לחץ פעמיים על run_windows.bat.
4. בפעם הראשונה הדבק בחלון את מפתח Gemini API ולחץ Enter.
5. השרת ייצור מקומית config.json ויציג קוד גישה. שמור את הקוד; אל תשתף אותו.
6. השרת יציג את כתובת המחשב. השאר את החלון פתוח בזמן השימוש.

## חיבור אפליקציית Android
1. ודא שהטלפון והמחשב באותה רשת Wi-Fi.
2. פתח באפליקציה הגדרות (⚙) ובחר Gemini – Google.
3. סמן "להתחבר ל-Gemini דרך מחשב Windows".
4. בשדה כתובת השרת רשום את הכתובת שהשרת הציג, לדוגמה: http://192.168.1.20:8765/gemini
5. בשדה קוד הגישה הדבק את הקוד שהשרת הציג.
6. שמור הגדרות ונסה לשלוח הודעה.

## Firewall
אם Windows מציג בקשת Firewall, אפשר גישה ל-Python ברשת פרטית בלבד. אין לאפשר גישה ברשתות ציבוריות. אם צריך, אפשר TCP נכנס בפורט 8765 בפרופיל Private בלבד.

## אבטחה
- מפתח Gemini נשמר רק בקובץ config.json המקומי, שמוחרג מ-Git.
- קוד גישה מגן על נקודת הגישה של השרת.
- התקשורת מהטלפון למחשב היא HTTP ברשת המקומית; השתמש רק ב-Wi-Fi פרטי ומהימן, ולא ברשת ציבורית.
- החיבור מהמחשב ל-Google Gemini הוא HTTPS עם אימות תעודות רגיל.
- אל תעלה את config.json ל-GitHub ואל תשתף את קוד הגישה.
- השרת אינו מיועד לחשיפה לאינטרנט. אין להגדיר Port Forwarding בנתב.

## פתרון תקלות
- בדוק ששני המכשירים באותה רשת ושכתובת ה-IP נכונה.
- בדוק שהשרת עדיין פועל וש-Windows Firewall מאפשר חיבור ברשת פרטית.
- פתח בדפדפן הטלפון http://כתובת-המחשב:8765/health. אמורה להופיע תשובת JSON עם ok=true.
- שגיאת 401 פירושה שקוד הגישה באפליקציה אינו תואם לקוד שבחלון השרת.
