# צ׳אט AI – Android 4.4

אפליקציית צ׳אט בעברית עם שני ספקי AI מובנים: Google Gemini ו־OpenAI GPT.

## תאימות
- מינימום Android 4.4 (API 19).
- קוד Java ללא ספריות Native; מתאים למכשירי 32 ביט.
- ממשק עברי RTL ושמירת שיחות מקומית.
- תקשורת HTTPS בלבד לספקי ה־API המוגדרים כברירת מחדל.

## הגדרת הספק
בהגדרות האפליקציה קיימים שני אזורים נפרדים:
1. **Google Gemini** – מפתח API, מודל וכתובת API.
2. **OpenAI GPT** – מפתח API, מודל וכתובת API.

בוחרים בחלק העליון איזה ספק יהיה פעיל לשיחה. ברירות המחדל הן `gemini-2.5-flash` ו־`gpt-4o-mini`. יש להזין מפתח API משלך לכל ספק שבו רוצים להשתמש.

## HTTPS ו־TLS
Android 4.4 תומך ב־TLS 1.2 אך אינו מפעיל אותו כברירת מחדל בחיבורי לקוח. האפליקציה מפעילה TLS 1.2 בחיבורי HTTPS במכשירי API 16–19, תוך שמירה על אימות התעודה ושם השרת של Android. אין עקיפה של אימות SSL ואין TrustManager שמאשר כל תעודה.
תהליך GitHub Actions כולל בדיקות handshake לשרתי Gemini ו־OpenAI על אמולטור Android 4.4 (API 19).

## בנייה והורדה
בכל push ל־main מתבצעת בנייה. את ה־APK מורידים מ־GitHub → Actions → Build Android APK → Artifacts → HebrewAIChat-APK.

## פרטיות ועלויות
מפתחות API נשמרים בהעדפות המקומיות של האפליקציה ואינם נכתבים למאגר. אין מפתח חינמי מובנה; השימוש במודלים כפוף לתנאי הספק ולחיוב שלו. מכשירי Android 4.4 ישנים עשויים להכיל מאגר תעודות שורש מיושן, ולכן הצלחת HTTPS תלויה גם בעדכוני האבטחה של המכשיר.
