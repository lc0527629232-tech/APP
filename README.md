# צ׳אט AI – Android

אפליקציית צ׳אט בעברית, Java Native, עם ממשק RTL, שמירת היסטוריה מקומית וחיבור לשרת API תואם OpenAI Chat Completions.

## תאימות
- מינימום Android API 14 (Android 4.0).
- קוד Java ללא ספריות Native, ולכן אין תלות ב-64 ביט בלבד.
- ממשק Holo כדי לתמוך בגרסאות Android ישנות.
- נדרש חיבור אינטרנט ומפתח API מספק מודל AI.

## בנייה
ה־GitHub Actions בונה APK מסוג debug בכל push ל-main. את הקובץ מורידים מ-Actions → Build Android APK → Artifacts → HebrewAIChat-APK.

## הפעלה
פתחו את הגדרות האפליקציה והזינו מפתח API, כתובת API (ברירת מחדל: https://api.openai.com/v1/chat/completions) ושם מודל. המפתח נשמר בהעדפות הפרטיות של האפליקציה במכשיר ולא נמצא בקוד המאגר.

## הערות
- האפליקציה אינה כוללת מפתח API חינמי. השימוש בשירות מודל עשוי להיות כרוך בתשלום לפי ספק ה-API.
- Android 4 ישן מאוד; חיבורי HTTPS מודרניים עשויים שלא לעבוד בכל מכשיר/גרסת מערכת בגלל תמיכת TLS ותעודות מערכת מיושנות.
- קובץ debug APK מתאים להתקנה ובדיקה, אך אינו חתום במפתח הפצה פרטי.
