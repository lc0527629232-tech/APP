# צ׳אט AI – Android 4.1.2+

אפליקציית צ׳אט בעברית עם שני ספקי AI מובנים: Google Gemini ו־OpenAI GPT.

## תאימות
- מינימום Android 4.1.2 (API 16).
- קוד Java ללא ספריות Native; מתאים גם למכשירי 32 ביט.
- ממשק עברי RTL ושמירת שיחות מקומית.
- ברירות המחדל של ספקי ה־API משתמשות ב־HTTPS.

## הגדרת הספק
בהגדרות האפליקציה קיימים שני אזורים נפרדים:
1. **Google Gemini** – מפתח API, מודל וכתובת API.
2. **OpenAI GPT** – מפתח API, מודל וכתובת API.

בוחרים בחלק העליון איזה ספק יהיה פעיל לשיחה. ברירות המחדל הן `gemini-2.5-flash` ו־`gpt-4o-mini`. יש להזין מפתח API משלך לכל ספק שבו רוצים להשתמש.

## HTTPS ו־TLS
האפליקציה משתמשת ב־HTTPS ובאימות תעודות ושם שרת הרגיל של Android; אין עקיפה של אימות SSL. בקוד מופעל TLS 1.2 כאשר מערכת Android מדווחת שהוא נתמך, עבור API 16–19. בדיקת handshake אוטומטית מול שרתי Google Gemini ו־OpenAI מוגדרת באמולטור Android 4.4 (API 19). היא אינה מוכיחה שכל מכשיר Android 4.1.2 יתחבר: הדבר תלוי בגרסת TLS ובתעודות השורש שמותקנות במכשיר.

## בנייה והורדה
בכל push ל־main מתבצעת בנייה. את ה־APK מורידים מ־GitHub → Actions → Build Android APK → Artifacts → HebrewAIChat-APK.

## פרטיות ועלויות
מפתחות API נשמרים בהעדפות המקומיות של האפליקציה ואינם נכתבים למאגר. אין מפתח חינמי מובנה; השימוש במודלים כפוף לתנאי הספק ולחיוב שלו.
